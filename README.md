# Носики — интерактивная энциклопедия о носах животных

Сайт для Стеши (2 года 8 месяцев): какие бывают носы у животных, почему они такие
и у кого какой. 53 животных, 12 типов носов.

## Главное в устройстве

**Ребёнок в 2,8 не читает.** Поэтому текст на экране — для взрослого, а интерфейс
для ребёнка это фотографии, крупные кнопки (минимум 92×92 px) и голос. На каждой
карточке два слоя: «детский» — звучит голосом, без цифр и терминов; «для взрослых» —
точная формулировка со ссылкой на источник.

**Достоверность проверяется, а не предполагается.** Факты взяты из English Wikipedia,
ссылка есть на каждой карточке. Там, где источники расходятся или популярное
объяснение не подтверждается (нос сайгака, охота киви «только по запаху»,
чувствительность нюха собаки) — это прямо помечено в слое для взрослых.

**Приёмка медиа формальная.** `scripts/validate.mjs` падает, если у животного нет фото,
кропа носа, лицензии, озвучки или отметки о том, что нос на кропе виден. Есть стоп-лист
(`scripts/safety.mjs`): мёртвые животные, капканы, охота, черепа не проходят.
Изображения, сгенерированные ИИ, отклоняются — нужны настоящие фотографии.

## Запуск

```bash
npm install
npm run build        # перед сборкой прогоняется приёмка
npm run serve        # http://localhost:8080
```

## Медиа-пайплайн

Скрипты в `scripts/` запускаются один раз и складывают результат в `public/media`:

| Скрипт | Что делает |
|---|---|
| `openverse-photos.mjs` | ищет фото (Openverse: Flickr CC + Викисклад) |
| `apply-replacements.mjs` | качает отобранные вручную файлы |
| `fetch-sounds.mjs` | живые записи CC0 через Openverse |
| `gen-sfx.mjs` | звук для видов без записи (ElevenLabs) |
| `gen-voice.mjs` | русская озвучка (ElevenLabs), кэш по хешу текста |
| `validate.mjs` | приёмочный гейт |
| `gen-attributions.mjs` | собирает `ATTRIBUTIONS.md` |

Отбор фотографий — ручной: поисковая выдача шумная (на запрос «elephant» приходит
туманность «Хобот слона», на «pig snout» — музейная чаша). Скрипт готовит кандидатов,
человек смотрит контактный лист и выбирает.

## Что где живёт

- Боевой адрес: https://aninose.containerapps.ru
- Образ: `aninose.cr.cloud.ru/aninose` (Artifact Registry проекта Cloud.ru)
- Приложение: Container Apps `aninose`, порт 8080

### Развернуть заново

```bash
docker build -t aninose:N .
docker save aninose:N -o /tmp/aninose.tar
GODEBUG=http2client=0 crane push /tmp/aninose.tar aninose.cr.cloud.ru/aninose:N
GODEBUG=http2client=0 evo ca deploy aninose --image aninose.cr.cloud.ru/aninose:N \
  --port 8080 --cpu 1 --memory 1Gi --min-instances 1 --max-instances 3 --public --yes
```

`GODEBUG=http2client=0` обязателен из окружения с прокси: прокси сбрасывает HTTP/2
к `*.cloud.ru`, по HTTP/1.1 всё проходит. По той же причине `docker push` напрямую
не работает и образ заливается через `crane`.

## Честно о недоделанном

- **Звук.** Живые записи CC0 нашлись для 21 вида, для остальных 32 звук
  сгенерирован. Генерация узнаваемая, но это не полевая запись.
- **Два кропа слабее прочих.** У белки кадр нерезкий, у носорога в кроп попадает
  рог и кожа, а не ноздри — исходных фотографий лучше не нашлось под свободной лицензией.
- **Прогресс альбома.** На сервере он лежит в `/tmp` и обнуляется при перезапуске
  контейнера; надёжное хранилище — `localStorage` в браузере. Для одного ребёнка
  этого достаточно, но если нужен альбом между устройствами — нужен S3 или БД.
- **Озвучка синтезированная.** Голос ElevenLabs, не живой. Записать папиным
  голосом — отдельная возможность, её пока нет.
